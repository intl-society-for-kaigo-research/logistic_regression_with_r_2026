4  ロジスティック回帰

4.1 はじめに

医療・保健・スポーツ科学分野では、

  • 転倒したか
  • 死亡したか
  • 入院したか
  • 疾患を有するか

のように、

「はい / いいえ」

で表されるアウトカムを扱うことが多い。

このようなアウトカムを、二値アウトカム（binary outcome）という。

ロジスティック回帰（logistic regression）は、二値アウトカムを解析する代表的な統計手法である。

4.2 二値アウトカム

二値アウトカムとは、結果が2種類しかない変数である。

例：

アウトカム 値
生存 1
死亡 0
アウトカム 値
転倒あり 1
転倒なし 0
アウトカム 値
糖尿病あり 1
糖尿病なし 0

通常、解析では：

  • 1 = イベントあり
  • 0 = イベントなし

として扱うことが多い。

4.3 なぜ線形回帰ではいけないのか

二値アウトカムに対して、通常の線形回帰（linear regression）を用いることには問題がある。

例えば：

\[ Y = \beta\_0 + \beta\_1X \]

をそのまま適用すると、予測値が：

  • 0未満
  • 1を超える

可能性がある。

しかし、確率は：

\[ 0 \leq p \leq 1 \]

でなければならない。

また、二値データでは誤差分布も正規分布を仮定しにくい。

このため、二値アウトカムには別のモデルが必要となる。

4.4 ロジスティック回帰の考え方

ロジスティック回帰では、

確率そのもの

ではなく、

オッズの対数（log odds）

をモデル化する。

まず、確率を (p) とする。

オッズは：

\[ \frac{p}{1-p} \]

である。

さらに、その対数を取る：

\[ \log\left(\frac{p}{1-p}\right) \]

これをロジット（logit）という。

4.5 ロジスティック回帰モデル

ロジスティック回帰では、

()=_0+_1X

というモデルを用いる。

ここで：

  • (p)：イベントが起こる確率
  • (_0)：切片
  • (_1)：回帰係数
  • (X)：説明変数

である。

4.6 ロジット変換

ロジット変換を行うことで、

\[ 0 \leq p \leq 1 \]

という制約を回避できる。

ロジット値は：

\[ -\infty \sim +\infty \]

を取りうるため、通常の回帰モデルの形で扱いやすくなる。

4.7 回帰係数の意味

ロジスティック回帰では、回帰係数 () は：

log odds の変化量

を意味する。

しかし、log odds は直感的ではない。

そこで通常は、指数変換を行う。

4.8 オッズ比への変換

回帰係数を指数変換すると：

\[ OR=e^{\beta} \]

となる。

つまり、ロジスティック回帰の結果は、オッズ比として解釈できる。

4.9 例：年齢と転倒

例えば：

  • アウトカム：転倒の有無
  • 説明変数：年齢

を解析したとする。

結果が：

\[ \beta = 0.08 \]

であれば：

\[ e\^{0.08} \approx 1.08 \]

となる。

これは：

年齢が1歳上がるごとに、転倒オッズが1.08倍になる

と解釈できる。

4.10 単変量と多変量

4.10.1 単変量ロジスティック回帰

1つの説明変数のみを用いる。

例：

  • 年齢 → 転倒

4.10.2 多変量ロジスティック回帰

複数の説明変数を同時に扱う。

例：

  • 年齢
  • 性別
  • BMI
  • 運動習慣

を同時に投入する。

これにより、

他の変数を調整した上での関連

を評価できる。

4.11 ロジスティック回帰の出力

一般的には：

  • 回帰係数（β）
  • オッズ比（OR）
  • 95%信頼区間
  • p値

が出力される。

例：

変数 OR 95%CI p
年齢 1.08 1.03–1.13 <0.001

4.12 ロジスティック回帰の特徴

ロジスティック回帰には、以下の特徴がある。

4.12.1 長所

  • 二値アウトカムを扱える
  • 解釈しやすい
  • 医学論文で広く用いられる
  • 調整解析が可能

4.12.2 短所

  • オッズ比の誤解が起こりやすい
  • 非線形関係に弱い場合がある
  • 希少イベントでは不安定になることがある

4.13 ロジスティック回帰と因果関係

ロジスティック回帰は、

関連（association）

を評価する手法である。

したがって、

ロジスティック回帰を行っただけでは因果関係は証明できない

点に注意が必要である。

交絡因子や研究デザインを考慮する必要がある。

4.14 まとめ

  • ロジスティック回帰は二値アウトカムを扱う手法である
  • 確率ではなく log odds をモデル化する
  • ロジット変換を用いる
  • 回帰係数を指数変換するとオッズ比になる
  • 多変量解析により調整が可能である
  • ロジスティック回帰は関連を評価する手法である
